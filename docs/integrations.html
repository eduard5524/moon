Integrations

Moon integrates with the tools and services that power modern software development.

Git

Full Git integration for version control operations.

Supported Operations

  • Clone, fetch, pull, push
  • Branch creation and management
  • Commit with meaningful messages
  • Pull request creation and updates
  • Merge conflict resolution
  • Interactive rebase

Supported Platforms

  • GitHub (Cloud & Enterprise)
  • GitLab (Cloud & Self-hosted)
  • Bitbucket
  • Azure DevOps

Configuration

# .moon/integrations/git.yaml
git:
  platform: github
  auto_commit: true
  commit_style: conventional  # feat:, fix:, refactor:, etc.
  branch_prefix: moon/
  
  pull_requests:
    auto_create: true
    draft: false
    reviewers: ["@team-lead"]
    labels: ["ai-generated"]
    
  hooks:
    pre_commit:
      - lint
      - type-check
    pre_push:
      - test

Docker

Container-based isolation for safe code execution and deployment.

Features

  • Sandboxed execution environments
  • Multi-stage build optimization
  • Docker Compose for multi-service setups
  • Registry push/pull
  • Image layer caching

Configuration

# .moon/integrations/docker.yaml
docker:
  enabled: true
  runtime: docker           # or podman
  
  sandbox:
    image: moon-sandbox:latest
    memory_limit: 4g
    cpu_limit: 2
    network: bridge
    volumes:
      - ./:/workspace:rw
  
  build:
    cache: true
    multi_stage: true
    target_size: minimal
  
  registry:
    url: ghcr.io
    username: ${GITHUB_USER}
    token: ${GITHUB_TOKEN}

Terminal & SSH

Execute commands locally or on remote machines.

Capabilities

  • Execute shell commands (bash, zsh, fish)
  • Interactive process management
  • SSH access to remote servers
  • Port forwarding and tunneling
  • Background process monitoring

Configuration

# .moon/integrations/terminal.yaml
terminal:
  shell: bash
  timeout: 300              # seconds
  
  ssh:
    hosts:
      production:
        host: prod.example.com
        user: deploy
        key: ~/.ssh/deploy_key
      staging:
        host: staging.example.com
        user: deploy
        key: ~/.ssh/deploy_key
  
  safety:
    blocked_commands:
      - "rm -rf /"
      - "dd if=/dev/zero"
    require_approval:
      - "sudo"
      - "systemctl"

Browser

Web browsing capabilities for research, testing, and interaction.

Features

  • Browse documentation and references
  • Interact with web UIs (Playwright)
  • Screenshot and visual testing
  • API exploration via browser dev tools
  • OAuth/SSO authentication flows

Configuration

# .moon/integrations/browser.yaml
browser:
  engine: chromium
  headless: true
  
  permissions:
    - navigate
    - screenshot
    - interact
    - download
  
  blocked_domains:
    - "*.malware.example"
  
  viewport:
    width: 1920
    height: 1080

Cloud Providers

Deploy and manage infrastructure across major cloud providers.

AWS

# .moon/integrations/cloud/aws.yaml
aws:
  region: us-east-1
  services:
    - ecs
    - lambda
    - s3
    - rds
    - cloudfront
  
  credentials:
    access_key: ${AWS_ACCESS_KEY_ID}
    secret_key: ${AWS_SECRET_ACCESS_KEY}
  
  defaults:
    ecs:
      cluster: production
      service: web-app
    lambda:
      runtime: python3.11
      memory: 256

Google Cloud

# .moon/integrations/cloud/gcp.yaml
gcp:
  project: my-project-id
  region: us-central1
  services:
    - cloud-run
    - cloud-functions
    - cloud-sql
    - gcs
  
  credentials:
    service_account: ${GCP_SERVICE_ACCOUNT_KEY}

Azure

# .moon/integrations/cloud/azure.yaml
azure:
  subscription: ${AZURE_SUBSCRIPTION_ID}
  resource_group: production
  services:
    - container-apps
    - functions
    - cosmos-db
    - blob-storage
  
  credentials:
    tenant_id: ${AZURE_TENANT_ID}
    client_id: ${AZURE_CLIENT_ID}
    client_secret: ${AZURE_CLIENT_SECRET}

Memory Store

Persistent storage for agent memory and context.

Backends

Backend Use Case Performance
SQLite Local development Fast, zero-config
PostgreSQL Production, team use Scalable, concurrent
Redis Working memory cache Ultra-fast reads
Pinecone/Weaviate Vector search Semantic similarity

Configuration

# .moon/integrations/memory.yaml
memory:
  backend: sqlite           # sqlite, postgres, redis
  path: .moon/memory.db
  
  vector_store:
    backend: local          # local, pinecone, weaviate
    embedding_model: text-embedding-3-small
    dimensions: 1536
  
  retention:
    working_memory: 1h
    episodic: 30d
    semantic: forever
