Getting Started

This guide will help you set up Moon and run your first autonomous task in minutes.

Prerequisites

  • Python 3.10 or later
  • Docker (for containerized execution)
  • Git
  • An API key for your preferred LLM provider (OpenAI, Anthropic, etc.)

Installation

Using pip

pip install moon-agent

Using Docker

docker pull eduard5524/moon:latest
docker run -it --rm \
  -v ~/.moon:/root/.moon \
  -v /var/run/docker.sock:/var/run/docker.sock \
  eduard5524/moon:latest

From Source

git clone https://github.com/eduard5524/moon.git
cd moon
pip install -e ".[dev]"

Configuration

Create a configuration file at ~/.moon/config.yaml:

# ~/.moon/config.yaml
llm:
  provider: openai          # or anthropic, local
  model: gpt-4             # model identifier
  api_key: ${OPENAI_API_KEY}  # environment variable reference

agent:
  max_iterations: 50       # max steps per task
  approval_required: true  # ask before destructive actions
  sandbox: docker          # execution environment

integrations:
  git:
    auto_commit: true
    branch_prefix: moon/
  docker:
    enabled: true
  cloud:
    provider: aws          # aws, gcp, azure
    region: us-east-1

Quick Start

1. Initialize in your project

cd your-project
moon init

This analyzes your project structure and creates a .moon/ directory with project-specific configuration.

2. Run your first task

# Fix a bug
moon run "Fix the null pointer exception in UserService.java"

# Add a feature
moon run "Add pagination to the /api/users endpoint"

# Refactor code
moon run "Extract the validation logic into a separate middleware"

# Write tests
moon run "Add unit tests for the PaymentProcessor class"

3. Review and approve

Moon will:

  1. Analyze the codebase and plan the approach
  2. Execute the plan step by step
  3. Run tests to verify the changes
  4. Open a PR or ask for approval before deploying
