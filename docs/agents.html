Specialized Agents

Moon's multi-agent architecture delegates work to specialized agents, each optimized for a specific domain of software engineering.

Coding Agent

The Coding Agent is responsible for all code generation, modification, and refactoring tasks. It understands project structure, coding conventions, and language-specific best practices.

Capabilities

  • Code Generation — Write new files, functions, classes, and modules
  • Code Editing — Modify existing code with full context awareness
  • Refactoring — Extract methods, rename symbols, restructure modules
  • Dependency Management — Add/update packages, resolve conflicts
  • Multi-language — Python, TypeScript, JavaScript, Go, Rust, Java, C#, and more

How It Works

# The Coding Agent follows this workflow:

1. Receive task from Task Queue
2. Load relevant file context from Memory
3. Analyze code structure and dependencies
4. Plan modifications (AST-aware)
5. Apply changes with minimal diff
6. Validate syntax and imports
7. Report completion to Task Queue

Configuration

# .moon/agents/coding.yaml
coding_agent:
  style:
    follow_existing: true    # Match project conventions
    max_line_length: 100
    prefer_explicit_types: true
  
  safety:
    max_files_per_edit: 20   # Limit scope of changes
    require_tests: true      # Don't ship without tests
    lint_on_save: true       # Auto-fix lint issues
  
  languages:
    python:
      formatter: black
      linter: ruff
    typescript:
      formatter: prettier
      linter: eslint

Testing Agent

The Testing Agent ensures code quality by running existing tests, writing new ones, and diagnosing failures.

Capabilities

  • Test Execution — Run unit, integration, and e2e test suites
  • Test Generation — Write tests for new and existing code
  • Failure Diagnosis — Analyze test failures and identify root causes
  • Coverage Analysis — Track and improve code coverage
  • Regression Detection — Identify when changes break existing behavior

Testing Strategies

Strategy When Used Tools
Unit Testing After any code change pytest, jest, go test
Integration Testing API/service changes supertest, httpx, testcontainers
E2E Testing UI/workflow changes Playwright, Cypress
Property Testing Complex logic Hypothesis, fast-check
Mutation Testing Test quality validation mutmut, Stryker

Configuration

# .moon/agents/testing.yaml
testing_agent:
  coverage:
    minimum: 80              # Minimum coverage threshold
    fail_on_decrease: true   # Fail if coverage drops
  
  strategies:
    unit:
      enabled: true
      framework: auto-detect
    integration:
      enabled: true
      docker_compose: true
    e2e:
      enabled: false         # Enable manually
      browser: chromium

Documentation Agent

The Documentation Agent automatically generates and maintains documentation based on code analysis.

Capabilities

  • README Generation — Create and update project README files
  • API Documentation — Generate OpenAPI/Swagger specs from code
  • Code Comments — Add meaningful inline documentation
  • Change Logs — Auto-generate from commit history
  • Architecture Docs — Create system diagrams and explanations

Output Formats

  • Markdown (README, guides)
  • OpenAPI 3.0 (REST APIs)
  • GraphQL Schema docs
  • JSDoc / Python docstrings
  • Mermaid diagrams

Configuration

# .moon/agents/documentation.yaml
documentation_agent:
  auto_update: true         # Update docs on code changes
  formats:
    - markdown
    - openapi
  
  readme:
    sections:
      - overview
      - installation
      - usage
      - api
      - contributing
  
  api_docs:
    output: docs/api/
    format: openapi-3.0
    include_examples: true

Deployment Agent

The Deployment Agent handles building, packaging, and deploying applications across environments.

Capabilities

  • Container Building — Create optimized Docker images
  • CI/CD Pipeline — Configure and manage build pipelines
  • Cloud Deployment — Deploy to AWS, GCP, Azure, or custom infrastructure
  • Environment Management — Handle staging, production, and preview environments
  • Rollback — Automatically rollback on failed health checks

Supported Platforms

Platform Deployment Types
AWS ECS, Lambda, EC2, S3
Google Cloud Cloud Run, GKE, App Engine
Azure Container Apps, AKS, Functions
Vercel Serverless, Edge Functions
Fly.io Containers, Machines
Kubernetes Any K8s cluster

Configuration

# .moon/agents/deployment.yaml
deployment_agent:
  default_platform: docker
  
  environments:
    staging:
      auto_deploy: true      # Deploy on PR merge
      url: https://staging.example.com
    production:
      auto_deploy: false     # Require manual approval
      url: https://example.com
      health_check: /api/health
      rollback_on_failure: true
  
  docker:
    registry: ghcr.io/eduard5524
    build_args:
      NODE_ENV: production
  
  notifications:
    slack: "#deployments"
    on_success: true
    on_failure: true

Agent Communication

Agents communicate through the Task Queue using structured messages:

{
  "from": "coding_agent",
  "to": "testing_agent",
  "type": "task_complete",
  "payload": {
    "files_changed": ["src/auth/login.ts", "src/auth/middleware.ts"],
    "summary": "Added JWT validation middleware",
    "tests_needed": true
  }
}

Creating Custom Agents

You can extend Moon with custom agents for domain-specific tasks:

from moon import Agent, task

class SecurityAgent(Agent):
    name = "security"
    description = "Scans code for security vulnerabilities"

    @task("scan")
    async def scan_code(self, files: list[str]):
        # Run SAST tools
        results = await self.run_tool("semgrep", files)
        
        # Report findings
        for finding in results:
            await self.report(
                severity=finding.severity,
                file=finding.file,
                line=finding.line,
                message=finding.message
            )

# Register the agent
moon.register_agent(SecurityAgent)
