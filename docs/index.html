Moon Documentation

Welcome to the Moon documentation. Moon is an autonomous AI software engineer that can clone repositories, write code, run tests, open pull requests, and deploy servers — all on its own.

What is Moon?

Moon is a multi-agent AI system designed to handle the full software development lifecycle autonomously. Unlike simple code completion tools, Moon understands your entire project, plans complex tasks, and executes them end-to-end.

Moon doesn't just write code — it engineers solutions. From understanding requirements to deploying production-ready software.

Key Features

  • Autonomous Execution — Completes tasks without constant supervision
  • Multi-Agent Architecture — Specialized agents for coding, testing, docs, and deployment
  • Full Stack Access — Git, terminal, browser, SSH, Docker, and cloud providers
  • Context Awareness — Understands your codebase structure, patterns, and conventions
  • Human-in-the-Loop — Asks for approval on critical decisions

Architecture Overview

Planner
   |
Task Queue
   |
--------------------
Agent 1 -> Coding
Agent 2 -> Testing
Agent 3 -> Documentation
Agent 4 -> Deployment
--------------------
      |
Memory / Git / Docker / Browser / Terminal / SSH / Cloud

The system is built around a central Planner that decomposes user requests into executable tasks, a Task Queue that prioritizes and distributes work, and Specialized Agents that execute each step with access to the full development toolkit.
